Deskmate is a service desk web app for teams to report and resolve support requests.

## For both sides of support

- **Requesters** submit tickets and read saved resolution replies and knowledge-base articles.
- **Support Officers** resolve tickets, write and edit articles, and perform Requester password resets.

## Get started

Create a demo workspace to get accounts for both roles, then follow the [User Guide](https://github.com/CS3227-2610-MP3-Deskmate/CS3227-2610-MP3/blob/main/docs/UserGuide.md).
